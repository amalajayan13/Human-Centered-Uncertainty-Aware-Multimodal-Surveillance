# An Analyst-Oriented Uncertainty-Aware Multimodal Framework for Traceable Physical–Cyber Threat Interpretation: A Controlled Cross-Modal Feasibility Study

## Reproducibility
This repository contains the Jupyter notebook used for the analysis in the preparation of the manuscript. The notebook `main-v2.ipynb` can be opened directly in Google Colab or on a local machine. The .yaml file `conda-env.yaml` contains the conda environment configuration used to run the script on the local machine using Anaconda. Change the paths accordingly.

https://research.unsw.edu.au/projects/toniot-datasets, https://unsw-my.sharepoint.com/:f:/g/personal/z5025758_ad_unsw_edu_au/EvBTaetotpdGnW7rJQ8fCvYBh8063CNeY9W33MpRsarJaQ?e=yZlnxW

## Software

Python 3.10.20 with NumPy 1.26.4, pandas 2.3.3, SciPy 1.15.3, scikit-learn 1.7.2, Matplotlib 3.10.8 and joblib 1.5.3. the environment is recorded in `tables/environment.json`.

## Checking the results without re-running

`verify_from_predictions.py` re-implements, from the manuscript's equations alone, the window construction, all fusion rules, the threshold-selection rule and the evaluation metrics, and applies them to the exported event-level predictions:

```
python verify_from_predictions.py outputs/CHBR_R1_v3/tables
```

It reproduces the branch metrics of Table 4 and the fusion results of Table 6 to machine precision.
